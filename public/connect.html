Як перевірити, що дані йдуть

Реальних продажів чекати не треба — є дві пісочниці, які шлють транзакції тим самим каналом:

/taps — 12 кранів: клацаєш по пиву, збираєш чек, тиснеш «Відправити». Найзручніше для перевірки візуалізації — ти контролюєш, що саме прилетить.
/emulator — випадкові чеки, вручну або автоматично кожні 15–120 сек. Зручно лишити ввімкненим фоном на час налаштування.

/viz — готова веб-візуалізація живого потоку. Відкрий її поруч і одразу побачиш, чи долітають дані (клавіша F — на весь екран).

Емульовані чеки мають номер > 900000 і поле _emulated: true — у своїй візуалізації їх можна відфільтрувати або підсвітити.

TouchDesigner — підключення

  1. Додай у проект ноду WebSocket DAT
  2. Параметр Network Address → вкажи WebSocket URL зверху
  3. Встанови Active = On
  4. У параметрі Callbacks DAT → вкажи Script DAT з кодом нижче
Python-скрипт для WebSocket DAT (Callbacks) 
import json

def onReceiveText(dat, rowIndex, message):
    try:
        tx = json.loads(message)

        # Сума та оплата
        total      = tx.get('sum', 0)
        pay_cash   = tx.get('payed_cash', 0)
        pay_card   = tx.get('payed_card', 0)
        duration   = tx.get('duration_sec')   # секунди або None
        tx_time    = tx.get('time', '')
        store      = tx.get('store_label', '')
        table      = tx.get('table')
        guests     = tx.get('guests')
        mode       = tx.get('service_mode')   # 1=зал 2=виніс 3=доставка

        # Продукти
        products   = tx.get('products', [])
        prod_count = len(products)
        categories = list({p.get('category') for p in products if p.get('category')})

        # Зберігаємо у Storage для доступу з інших нод
        storage = op('storage1')   # замінити на ім'я своєї Storage COMP
        storage.store('tx',            tx)
        storage.store('tx_sum',        total)
        storage.store('tx_pay_cash',   pay_cash)
        storage.store('tx_pay_card',   pay_card)
        storage.store('tx_duration',   duration or 0)
        storage.store('tx_prod_count', prod_count)
        storage.store('tx_categories', categories)
        storage.store('tx_table',      table or '')
        storage.store('tx_guests',     guests or 0)
        storage.store('tx_mode',       mode or 0)

        print(f'[Poster] #{tx["transaction_id"]} | {total} грн | {prod_count} поз. | {store}')

    except Exception as e:
        print(f'[Poster] parse error: {e}')
