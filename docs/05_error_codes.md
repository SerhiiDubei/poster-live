# Poster API — Коди помилок

Source: https://dev.joinposter.com/en/docs/v3/web/errors

## Формат помилки

```json
{
  "error": {
    "code": 11,
    "message": "Bad access token"
  }
}
```

## Загальні помилки Web API

| Код | Опис |
|---|---|
| `0` | Success |
| `10` | access_token не вказано |
| `11` | Невалідний access_token |
| `12` | access_token протермінований |
| `20` | Додаток не авторизований викликати цей метод |
| `32` | ID не існує |
| `34` | Відсутні обов'язкові параметри |
| `36` | Змінна повинна бути масивом |
| `38` | Назва вже існує |
| `42` | Змінна не існує |
| `44` | Помилка збереження даних |
| `45` | Час менший за час відкриття замовлення |
| `52` | Діапазон дат не може перевищувати 3 дні |
| `54` | Доступ заборонено |
| `99` | Дублювання сутності |
| `142` | Невалідний verify |
| `143` | Невалідний application_id |
| `153` | Зміни не дозволено |
| `154` | Назва модифікатора має бути унікальною |
| `155` | Пряме значення параметра |
| `168` | Статус обробки не підходить |
| `169` | Режим обслуговування не підходить |
| `400` | Невалідний формат запиту, відсутні обов'язкові дані |
| `404` | Запис не знайдено |
| `700` | Rate limit |
| `701` | Поле має бути цілим числом |
| `4001` | Невалідна валюта |

## Помилки методів розділу Orders

| Код | Опис |
|---|---|
| `1` | Неможливо зберегти в БД |
| `41` | Продукт не знайдено |
| `42` | Модифікація продукту не знайдена / Замовлення не знайдено |
| `43` | Продукт у замовленні не знайдено |
| `44` | Акцію не знайдено |
| `45` | Неможливо прив'язати акцію до замовлення |
| `46` | Кількість продуктів >= 0 |
| `47` | Акцію не знайдено |
| `49` | Гостя не знайдено |
| `50` | Відсутні обов'язкові параметри |
| `60` | Локацію не знайдено |
| `88` | Сума продуктів не дорівнює сумі оплати |
| `185` | Час доставки в минулому |
